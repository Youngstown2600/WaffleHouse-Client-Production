WaffleHouse-Client 5.1r3 — validation
=====================================
Date: 2026-08-30

Scope
-----
5.1r3 adds local AIM/OSCAR and IRC account labels, makes all twelve dial-pad
buttons geometrically identical across Qt platform styles, and compacts the
Active Calls control bank into two primary rows plus DTMF/Diagnostics.

Account labels
--------------
- Shared ConnectionSettings::accountLabel is persisted by GUI and CLI.
- The Connection dialog exposes Account label only for AIM/OSCAR and IRC.
- Labels affect local account presentation only; username/screen name/nickname
  and server connection fields are unchanged.
- GUI account tree/context menu/connections list and CLI connection labels use
  the friendly label when present.

Softphone
---------
- Every dial key uses the same fixed 76x58 geometry and fixed QSizePolicy.
- Keypad rows/columns enforce uniform minimum geometry.
- Active call primary controls occupy two four-button rows.
- Transfer labels are shortened on-button with full tooltips.
- Live-call buttons are capped at 34 px high.

Inherited behavior
------------------
The full 5.1r2 + r20 regression set is retained, including OSCAR Away/Idle
hydration, printable unsecured transfer framing, OSCAR audit logs/viewer,
ChatNav redirect behavior, NINA compatibility, IM composer focus, multi-SIP,
macOS deployment gates, and cross-platform uninstall/remove behavior.

Native-build limitation in this execution environment
-----------------------------------------------------
A fresh CMake configure successfully reached compiler and pthread detection,
then stopped at `find_package(Qt6)` because this execution environment does not
provide Qt6Config.cmake / qt6-config.cmake. Therefore this report does not claim
a fresh native Qt link in the sandbox.
