--------------------

FreeBSD    : GUI + CLI use shared src/oscarbackend.cpp.
macOS      : GUI + CLI use shared src/oscarbackend.cpp.
Windows    : GUI + CLI use shared src/oscarbackend.cpp; MSYS2/UCRT64 builder added.
Termux     : GUI + CLI use shared src/oscarbackend.cpp; native Termux builder added.

Environment limitation
----------------------
A full native Qt compile could not be executed in this sandbox because Qt6 development files (Qt6Config.cmake) are not installed. CMake parses the 5.1 project successfully through compiler/thread detection and stops at Qt6 dependency discovery. Windows and Termux builders were source/static-validated here but require their target environments for actual compilation/runtime testing.

The user-supplied NINAPatcher executable is NOT bundled in WaffleHouse-Client 5.1.
