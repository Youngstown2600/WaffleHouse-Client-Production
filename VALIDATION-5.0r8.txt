WaffleHouse-Client 5.0r8 — macOS optional-media dependency fix
================================================================

Scope
-----
5.0r8 starts from the 5.0r7 combined Linux/FreeBSD/macOS desktop bundle.
No OSCAR/NINA work from the interrupted 5.0r8 discussion was applied.

macOS builder fix
-----------------
- Fatal Homebrew dependency set is limited to compile/link requirements:
  cmake, pkg-config, qt, libsodium, ncurses, portaudio, opus.
- mpv and ffmpeg are runtime-only optional helpers.
- Default builds do not attempt to install optional media helpers.
- --with-media-deps explicitly opts into Homebrew attempts for mpv/ffmpeg.
- Optional Homebrew install failures are caught and do not abort the build.
- yt-dlp is no longer requested by the macOS builder.

macOS runtime discovery
-----------------------
Finder-launched apps may not inherit shell package-manager paths. Runtime
lookup now checks PATH plus /opt/homebrew/bin, /usr/local/bin, /opt/local/bin,
/sw/bin, and /Applications/mpv.app/Contents/MacOS/mpv where applicable.

Static validation
-----------------
- POSIX shell syntax: PASS for build.sh and all retained shell scripts.
- macOS builder no longer includes mpv/ffmpeg/yt-dlp in fatal need_formula loop: PASS.
- Optional brew install is guarded by an if statement and cannot trip set -e: PASS.
- Current branding/version surfaces report 5.0r8 / 5.0.8: PASS.
- Linux host routing still selects scripts/build-unix.sh: PASS.

Runtime limitation
------------------
This validation host is Linux. Native Homebrew/Cocoa compilation and execution
must be exercised on macOS; no native macOS runtime result is claimed here.

Simulated Darwin builder regression
-----------------------------------
A command-shim harness exercised scripts/build-macos.sh as a Darwin host:
- Default build with mpv/ffmpeg absent: PASS; no optional brew install attempted.
- --with-media-deps with fake "no bottle available" failures for both helpers:
  PASS; warnings emitted and build continued through app/deploy completion.
