WaffleHouse-Client 5.0r4 — pruned Unix/Linux release package
====================================================================
- Platform scope: Linux + FreeBSD only; retained FreeBSD audio helper, desktop entry, shell wrapper, PJSIP helpers, GUI/CLI source and required assets.
- Removed unrelated platform payloads and historical release clutter.
- Removed internal tests/examples/companion payloads from the shipping archive.
- CMake contains only the active build path for this platform bundle.
- All retained shell scripts pass sh -n syntax validation.
- OSCAR client-event typing notifications use the dedicated typing signal only; they are not emitted as generic conversation events.
- GUI generic-event handling defensively consumes any future "typing" event and updates only an already-open AIM IM window.
- Builder dry-run completed through dependency audit; this sandbox lacks the Qt6/PJSIP/media development stack required for a full link build.
