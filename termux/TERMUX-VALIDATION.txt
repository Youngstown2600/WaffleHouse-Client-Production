Build 1.1 startup microphone preflight
-------------------------------------
The installed client invokes wafflehouse-audio-preflight --startup before the
TUI. A successful permission/capture probe is silent. Missing Android capture
permission uses Termux:API's microphone request path so Android can surface its
runtime permission prompt. Failure is advisory and cannot block client startup;
Build 0.8+ speaker-only/null-audio SIP fallback remains available.
