WaffleHouse-Client 5.1r2 — validation
====================================
Date: 2026-08-30

Scope
-----
5.1r2 adds a first-class uninstall/remove lifecycle to the all-platform builder
while retaining the complete 5.1r1 GUI work and inherited 5.0r20 OSCAR/file-
transfer maintenance set.

Builder lifecycle
-----------------
- Linux/FreeBSD/macOS top-level interactive flow now asks Build/Install/Upgrade
  vs Uninstall/Remove before protocol selection or dependency work.
- Scripted desktop removal supports --uninstall and --remove-only.
- Linux/FreeBSD removes the installed client, /bin launcher, wafflehouse-shell,
  desktop entry, icons, and WaffleHouse shared sounds/resources.
- macOS removes the installed .app and command launcher before any Homebrew or
  build dependency checks.
- Termux supports interactive and scripted uninstall and removes the installed
  binary, GUI/CLI wrappers, shell helper, desktop entry, icons, and shared data.
- Windows remains a portable package; build-windows.ps1 -Uninstall removes the
  builder-managed dist/windows package.
- All removal paths deliberately preserve per-user WaffleHouse configuration,
  accounts, history, and logs.

17/17 project regressions PASS, including:
- BuildFeatures GUI declaration scope

Environment limitations
-----------------------
No PowerShell runtime is installed in this Linux container, so the Windows
PowerShell path was validated structurally by the 5.1r2 regression rather than
executed. No C++ application source behavior changed in this maintenance
revision; a fresh native Qt link was not claimed in this environment.
