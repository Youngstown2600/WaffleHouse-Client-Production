WaffleHouse-Client 5.0r15 validation
=====================================
Date: 2026-08-29

Scope
-----
5.0r15 is a GUI usability maintenance revision built directly from the 5.0r14
OSCAR-hardened desktop tree. It fixes initial keyboard focus in IM/chat windows
without changing OSCAR, IRC, Telnet/BBS, SIP, media, or secure-room behavior.

IM/chat focus fix
-----------------
- Read-only conversation transcripts now use Qt::ClickFocus. They remain
  selectable/copyable with the mouse but are removed from normal keyboard
  focus traversal/default-focus selection.
- ChatWindow::showEvent queues first-show focus to the QLineEdit message
  composer after Qt/window-manager activation processing completes.
- The queued focus is applied once per ChatWindow, so later user-selected focus
  is not continuously overridden.
- Terminal/BBS windows are unaffected because they do not create m_messageEdit.

Native-build limitation in this execution environment
-----------------------------------------------------
A fresh CMake configure was attempted with dependency auto-install disabled.
GNU C++ 14.2.0 and pthread support were detected successfully, but configuration
stopped at find_package(Qt6) because this execution environment does not provide
the Qt 6 development CMake package (Qt6Config.cmake/qt6-config.cmake). Therefore
this report does not claim a fresh native Qt link/runtime test here.
