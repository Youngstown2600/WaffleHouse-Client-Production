WaffleHouse-Client 5.0r16 validation
====================================
Date: 2026-08-29

Scope
-----
5.0r16 is a desktop compile-fix maintenance revision built directly from 5.0r15.

Compile fix
-----------
- src/mainwindow.cpp now directly includes src/buildfeatures.h.
- This resolves undeclared BuildFeatures errors in the connection dialog, menu/tray
  feature visibility, account loading, backend construction, and GUI command gates.
- No OSCAR, SIP, IRC, Telnet/BBS, media, or IM behavior was removed.

Regression coverage
-------------------
- Added tests/buildfeatures_gui_scope_test.sh.
- Existing OSCAR native feature audit, OSCAR idle/debug, IM input-focus, selectable
  protocol/multi-SIP/BBS, chan_sip, SIP server-type UI, and macOS deployment/linkage
  tests are retained and rerun for this revision.

Validation results
------------------
- 9/9 project regression scripts: PASS.
- Shell syntax: 15/15 project .sh scripts PASS via sh -n.
- BuildFeatures scope audit: PASS for every C++ source using BuildFeatures::.

Native-build limitation in this execution environment
-----------------------------------------------------
CMake compiler and thread detection succeeds, but this execution environment does not
contain the Qt 6 development CMake package (Qt6Config.cmake). Therefore this validation
does not claim a fresh native Qt link here. The reported 5.0r15 build failure occurred
later, while compiling mainwindow.cpp, and is directly addressed by adding the missing
buildfeatures.h include in that translation unit.
